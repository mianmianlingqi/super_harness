# /sh-remember — Super Harness 记忆维护

手动触发项目记忆（MEMORY.md）的更新和维护。

## 执行流程

### Step 1: 回顾当前会话

回顾本次会话中的关键事件：
- 做了什么决策？
- 遇到了什么意外？
- 学到了什么新模式？
- 项目状态有什么变化？

### Step 2: 检查 MEMORY.md 各板块

逐一检查 MEMORY.md 的每个板块是否需要更新：

#### Critical Gotchas（关键坑点）
- 有没有新发现的容易踩的坑？
- 有没有之前记录的坑已经过时了？

#### 架构决策（ADR）
- 有没有新的架构决策？用 ADR 格式记录：
  ```
  ### ADR-XXX: {标题}
  - **正题**: 方案 A 的优点
  - **反题**: 方案 A 的缺点 / 方案 B 的优点
  - **合题**: 最终选择及理由
  ```

#### Coding Conventions（编码约定）
- 有没有新的编码模式值得固化？
- 有没有现有约定需要更新？

#### 模块状态表
- 各模块的状态有没有变化？
- 有没有新模块需要加入？

### Step 3: 更新 MEMORY.md

用 Edit 工具精确修改 MEMORY.md 的对应板块。

### Step 4: 写入今日日志

如果有值得记录的经验教训，写入 `memory/YYYY-MM-DD.md`：

```markdown
# YYYY-MM-DD 会话记忆

## 本次确认
- [确认的事项]

## 记忆结论
- [学到的经验]
```

## 也可以用 MCP 工具

如果记忆库已经初始化，可以用 `search_memory` 查询已有记忆避免重复记录。
