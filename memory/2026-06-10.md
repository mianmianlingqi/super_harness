## 关键决策

- **ADR-005**: MCP Server 选择零依赖自实现 JSON-RPC，因为 `mcp` SDK 在 Python 3.9 不可用
- 用户明确去掉了 PLANNING 相关内容（check_planning hook、/sh-plan 命令、知识飞轮 Workflow）
- MCP 搜索需要语言匹配：中文数据需要中文查询（FTS5 不做翻译）

## 经验教训

1. **MCP 协议足够简单可以直接实现**：JSON-RPC 2.0 over stdin/stdout，核心只需 `initialize`、`tools/list`、`tools/call` 三个方法
2. **测试时要匹配数据语言**：FTS5 是关键词匹配，不会自动翻译
3. **先装数据再测搜索**：数据库没有数据时所有搜索都返回空，容易误判为 bug
